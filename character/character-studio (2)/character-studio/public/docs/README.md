# Character Studio

Локальный проект девушки за ноутбуком на основе утверждённой картинки. Работает без входа в аккаунт Rive и без интернета после установки зависимостей.

## Открыть

Linux/macOS: `./start-studio.sh` или `pnpm dev`. Windows: `Start-Studio.cmd`. Страница: http://127.0.0.1:5173, кофе по кругу: http://127.0.0.1:5173/?clip=coffee&repeat=1.

Первая установка: `pnpm install` (pnpm через `corepack enable pnpm`).

В студии можно выбрать одну из пяти готовых анимаций, остановить её, запустить сначала, поменять фон, сравнить с утверждённой картинкой, посмотреть 18 идей и скопировать промпт. Остальные 13 сцен помечены как идеи, а не готовые движения.

Редактор Rive для Windows установлен. Для локального просмотра он не требуется. Все ассеты и WASM runtime загружаются с этого компьютера.

## Что готово

- Rive CLI: `scripts/rive.mjs` ищет `RIVE_BIN`, `rive` в PATH, `~/.rive/bin/rive`, затем `tools/rive.exe` (на Linux — через wine). Нативная установка: `curl -fsSL https://releases.rive.app/cli/install.sh | sh`.
- Редактируемый проект Rive в `rive/scene.rml` и `rive/rive.yaml`.
- Настоящий файл `rive/build/office-character.riv`; копия для приложения в `public/rive/`.
- Основа: 82 контура, оттрассированных с утверждённого PNG. Для кофе добавлены цельная рука с отдельными плечом, предплечьем и кистью, два варианта кисти и кружка. Всего 9 костей. CoffeeCharacter — отдельная расширенная сцена 1440 × 1280; OfficeCharacter сохраняет базовый формат 1280 × 1280.
- 5 таймлайнов: `Idle_Work`, `Typing_Loop`, `Blink`, `Look_At_Viewer`, `Coffee_Sip`.
- Основная машина состояний `Character`, автоматически запускающая `Idle_Work`, и отдельные машины просмотра моргания, взгляда и печати.
- React 19, Vite 7, Ant Design 6, официальный Rive React Canvas runtime.
- Векторный исходник `assets/character-layered.svg` и карта частей `assets/rig-map.json`.
- Утверждённый референс `assets/reference-approved.png`.
- `ANIMATION-IDEAS.md` — 18 подробных промптов для анимаций.

## Первая анимация

«Спокойная работа» — 8-секундный цикл: неглубокое дыхание, лёгкое движение головы, короткие нажатия клавиш, моргание и перевод взгляда. В версии 2 амплитуда уменьшена: дыхание менее 1 px, взгляд до 5 px. Камера, стол и ноутбук неподвижны. Начальная и конечная позы совпадают.

## Продолжить работу

Точные контуры и части находятся в `assets/character-trace.json`, группы и ключевые кадры — в `scripts/build-character.mjs`. Версия 2 получена трассировкой утверждённого PNG. Градиенты сведены к плоским цветам; лицо, волосы, шея, руки и эмблема опираются на исходные контуры. Сравнение с первой версией: `comparison-v2.png`.

Для повторной трассировки используется `scripts/trace-reference.py`; её зависимости перечислены в `scripts/requirements-tracing.txt`. Обычная пересборка через Node не требует Python и повторной трассировки. Дополнительный исходник с исходными кривыми: `assets/character-traced-curves.svg`.

1. Изменить формы или тайминг в генераторе.
2. Запустить `pnpm character:rebuild` (или `./rebuild-character.sh`, `Rebuild-Character.cmd`): генератор → verify → inspect → `.riv` → `public/rive/` → документы.
3. Проверить кадры настоящего runtime: `pnpm capture -- --frames 0,72,200,420` (PNG в `captures/`; Chrome ищется автоматически, иначе `CHROME_PATH`).
4. Обновить локальную страницу.

Для просмотра в собственном окне Rive: `./preview-rive.sh` или `Preview-Rive.cmd`. Аккаунт не нужен.

Файл состоит из стандартных векторных объектов и ключевых кадров; внутри нет AnimaScript/Luau и нет удалённых ассетов. Поэтому локальный `.riv` проигрывается в браузерном runtime без облачной подписи. Вход Rive нужен только для облачной синхронизации, публикации и экспорта CLI в редакторский `.rev` — в текущем процессе это не используется.

## Ограничения первой версии

Части привязаны к настоящим RootBone и двигаются как жёсткие векторные элементы. Для кофе ключевые кадры рассчитаны по двухзвенной IK с неизменной длиной плеча и сокращением проекции предплечья при выносе руки вперёд. Деформация сеткой не используется. Моргание пока выполнено сжатием сборки глаза; для более выразительной мимики следует добавить отдельные веки. Для кофе добавлены открытая кисть, хват, скрытые участки торса и клавиатуры. Другим жестам понадобятся свои варианты кистей. Не считать 13 описанных сцен готовыми анимациями.

Проверка внешнего вида проводится в локальном React Canvas проигрывателе. Графический захват через Rive CLI 1.8.0 на этом компьютере показывает артефакты заливки; его PNG не следует использовать для публикации. Браузерная версия и SVG проверяются отдельно.

## Анимация 01 (переделка): глоток кофе по ключевым кадрам (итерация 13)

Открыть: http://127.0.0.1:5173/?clip=coffee&repeat=1. Артборд `CoffeeKeys` (1280 × 1280), таймлайн `Coffee_Keys`, машины `CoffeeKeysDemo`/`CoffeeKeysPreview`.

Источник — ключевые кадры пользователя `assets/coffee-ref/pose-{0-base,1-grip,2-lift,3-sip}.png`.
1. `.venv-tracing/bin/python scripts/trace-coffee-poses.py` — трассировка кадров целиком → `assets/coffee-poses.json`.
2. `.venv-tracing/bin/python scripts/coffee-pose-regions.py` — вырез руки с кружкой по цветам кожи/часов/кружки и их контуру, суставы E/W/M каждого кадра, заливки «за рукой».
3. `scripts/coffee-keys.mjs` — сцена: тело — кадр «у груди», неподвижно; рука каждого кадра натянута на две кости (локоть→запястье, запястье→кружка), между ключами кости интерполируются, рисунок руки меняется в середине движения. Место руки «у груди», когда она уходит, закрыто грудью из базового кадра и заливкой рукава.

Venv для трассировки: `python3 -m venv .venv-tracing && .venv-tracing/bin/pip install vtracer opencv-python-headless shapely Pillow numpy`.

## Анимация 06: нашла решение (итерация 8)

## Анимация 04: задумалась (итерация 6)

Открыть: http://127.0.0.1:5173/?clip=think&repeat=1. Таймлайн `Think` (4 с, один раз), машины `ThinkDemo`/`ThinkPreview`.

Руки замирают; за 0.5 с взгляд уходит вверх-вбок, ближняя бровь поднимается с лёгким поворотом, дальняя чуть опускается, голова наклоняется на 2°, улыбка разгибается почти в прямую. Выдержка 1.5 с с маленьким переводом глаз, моргание на 2.5 с, плавный возврат к базе к 3.3 с.

Открыть: http://127.0.0.1:5173/?clip=notification&repeat=1. Таймлайн `Notification` (3 с, один раз), машины `NotificationDemo` и `NotificationPreview` (по кругу).

## Анимация 02: слушает собеседника (итерация 4)

Открыть: http://127.0.0.1:5173/?clip=listen. Таймлайн `Listen` (6 с, цикл), машина `ListenDemo`.

Голова наклонена на 1.5° к зрителю и чуть покачивается, два медленных вдоха, на 2.1 с моргание (полузакрытие → дуги → открытие), на 3.3–4.4 с едва заметный кивок. Взгляд на зрителе, руки неподвижны на клавиатуре.

Чтобы голова могла наклоняться: силуэтный контур тела (контур 0) вокруг волос и клин у дальнего глаза перенесены в голову клип-маской; Rive обрезает по правилу non-zero, поэтому дырка в маске тела идёт в обратную сторону. Под стыками волос с плечом и капюшоном лежат тёмные подложки. Базовая поза не изменилась (расхождение 10 px сглаживания).

## Анимация 01: глоток кофе (итерация 3)

**Не принята:** рука гнётся неестественно, кисть непропорциональна. Отложено до переделки рига руки — см. `ROADMAP.md`.

Открыть: http://127.0.0.1:5173/?clip=coffee&repeat=1.

Семь секунд, одно действие: 0–0.6 с — кисть отрывается от клавиатуры и раскрывается; к 1.2 с — хват за ручку; 1.5–2.7 с — подъём к губам; 2.7–3.6 с — глоток с наклоном кружки и закрытыми глазами; до 5.0 с — кружка на столе; 5.2 с — ручка отпущена; к 6.5 с — кисть на клавиатуре; покой до 7 с.

Как устроено (`scripts/coffee-action.mjs`, рисунок — `scripts/coffee-art.mjs`):
- Риг CoffeeUpper → CoffeeForearm → CoffeeWrist. В покое используются оригинальные трассированные рукав-форма, часы и кисть «на клавиатуре», поэтому первый и последний кадры совпадают с референсом.
- Позы заданы явно (локоть, запястье, положение и наклон кружки), между ними — кубический Эрмит с остановками в ключевых позах; ключи пишутся каждые 2 кадра. Рукав и предплечье укорачиваются в проекции вдоль своей оси.
- Пока кружка в руке, запястье вычисляется из позы кружки — хват не «плывёт». Кружка на столе и в руке переключаются в кадре, где они совпадают.
- Кисти нарисованы заново: раскрытая (пальцы вместе, большой отведён) и кулак на ручке (цельный силуэт, три сгиба у кончиков, большой палец сверху). Масштаб 1.3 под ширину запястья референса.
- Кожа предплечья перерисована по трассированным краям с округлым локтем: в трассировке был впечатан край рукава.
- Передняя копия рукава закрывает основание предплечья у стола и гаснет при подъёме, чтобы предплечье шло перед рукавом.
- За персонажем — подложка торса (CoffeeTorsoFill): статичное плечо через клип-маску, бок и низ рубашки одной клеткой, низ футболки. Видна только там, где рука открывает торс.
- Глоток — закрытые глаза дугами (CoffeeClosedEyes), сами глаза скрыты.

Снимки поз: `assets/coffee-pose-{0,52,72,140,200,268,330,420}.svg`. Для просмотра по кругу используется CoffeePreview; производственный таймлайн Coffee_Sip однократный.
